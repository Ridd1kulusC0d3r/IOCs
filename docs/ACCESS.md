# Acesso, custo e direitos

[Início](../README.md)

| Código | Significado | O que não permite concluir |
|---|---|---|
| P | Conteúdo público sem cobrança de consulta indicada | API, uso comercial ou redistribuição livres |
| G | Gratuito mediante cadastro/chave | Quota ilimitada ou anonimato |
| F | Combinação de recursos gratuitos e pagos | Feed completo gratuito |
| $ | Oferta comercial | API/exportação inclusa no contrato |
| R | Aprovação, associação ou elegibilidade | Cobrança obrigatória |
| H | Histórico/arquivado | Atualização contínua |
| ? | Informação pendente | Gratuidade ou encerramento |

Os códigos podem coexistir. `verification.access=documented` significa que a documentação sustenta o modelo geral; ainda é necessário revisar a modalidade concreta que será usada. `provisional` é hipótese de classificação herdada da descoberta, não recomendação de compra.

## Casos documentados

- [URLhaus](https://urlhaus.abuse.ch/api/), [ThreatFox](https://threatfox.abuse.ch/api/) e [MalwareBazaar](https://bazaar.abuse.ch/api/): chave exigida; comunidade sob fair use e possibilidade de assinatura comercial.
- [VirusTotal](https://docs.virustotal.com/reference/public-vs-premium-api): API pública tem restrições para produtos, serviços e fluxos empresariais. Não classificar como “gratuito para SOC comercial”.
- [OpenPhish](https://openphish.com/phishing_feeds.html): Community e ofertas comerciais com cobertura e cadência distintas.
- [AbuseIPDB](https://www.abuseipdb.com/pricing): planos gratuitos e pagos, quotas diferentes.
- [urlscan](https://urlscan.io/pricing/): pesquisa gratuita não equivale ao acesso a todos os feeds.
- [n6](https://cert.pl/en/n6/): gratuito, com verificação de redes elegíveis.
- [threatYeti](https://www.threatyeti.com/): consulta Guest/Community e modalidades Pro/API.
- [Q-Feeds](https://qfeeds.com/): Community gratuito e ofertas comerciais.
- [APWG eCX](https://apwg.org/ecx): troca de dados entre membros; valor de associação não confirmado.

Não registrar preços numéricos sem data, moeda, unidade, modalidade e URL de evidência. Trial gratuito não deve ser classificado sozinho como freemium.
